# Агенты для проекта 7K Team × Oraz — Merch Shop

Кто нужен для создания красивого, профессионального магазина мерча.

---

## Приоритет 1: Без этого сайт не заработает

### 📸 Photographer / Art Director — Фотограф
**Самое важное.** Фото — это 80% успеха магазина мерча. Никакой код не спасёт плохие снимки.

**Что нужно снять:**
- Каждый товар на белом/нейтральном фоне (спереди, сзади, деталь)
- Лайфстайл-фото: команда в форме на тренировке
- Флэтлей (вид сверху): форма разложена красиво
- Крупный план фактуры ткани и швов

**Требования к файлам:**
- Соотношение сторон **4:5** для карточек (800×1000 px минимум)
- Формат JPG или WebP
- Положить в папку `images/`, назвать: `tshirt-1.jpg`, `tshirt-2.jpg`, `tshirt-back.jpg`

**После съёмки** скажи Claude: *"Замени заглушки на реальные фото"* — и всё сделается автоматически.

## Приоритет 2: Делают сайт красивым

### 🖌️ Visual Design Agent — Визуальный дизайнер
**Задача:** Поднять уровень дизайна — от "работает" до "вау".

**Что делает:**
- Создаёт дизайн-систему: точные цвета, размеры шрифтов, отступы
- Добавляет texture overlays, градиенты, геометрические акценты в стиле спортбренда
- Делает hero-секцию с полноэкранным изображением или видео
- Добавляет typographic hierarchy — крупные заголовки, контраст
- Следит за "дыханием" страницы — правильные whitespace

**Инструменты:** CSS, иногда Figma-макет как референс

**Пример запроса:**
> "Сделай hero более атмосферным — тёмный фон, диагональные линии, крупный слоган на весь экран. Стиль как у Nike или Gymshark."

---

### ✍️ Copywriter Agent — Копирайтер
**Задача:** Писать тексты, которые продают.

**Что делает:**
- Сочиняет сильные заголовки (hero, карточки, pop-up)
- Пишет описания товаров — коротко, энергично, с характером бренда
- Составляет CTA-кнопки (не "Заказать", а "Хочу эту форму")
- Создаёт tone of voice бренда 7K: дерзкий, мотивирующий, командный

**Пример запроса:**
> "Перепиши описание майки — сделай его энергичным, как будто говорит тренер перед забегом. Максимум 2 предложения."

---

### 🎞️ Motion / Animation Agent — Аниматор
**Задача:** Добавить жизнь и премиум-ощущение через анимации.

**Что делает:**
- Scroll-reveal: карточки товаров появляются при прокрутке
- Parallax в hero: логотип движется медленнее фона
- Hover-эффекты на кнопках и карточках
- Плавное открытие/закрытие модалки
- Skeleton loading пока грузятся фото

**Пример запроса:**
> "Добавь анимацию появления карточек при скролле — снизу вверх, с лёгким fade-in. Стаггер 100ms между карточками."

## Приоритет 3: Растут и масштабируются

### 📦 Catalog Agent — Менеджер каталога
**Задача:** Добавлять и редактировать товары.

**Файл:** `script.js` → массив `products`

**Структура товара:**
```js
{
  id: 'unique-id',
  name: 'Название',
  category: 'Категория',
  badge: null,           // 'Новинка' | 'Хит' | null
  description: '...',
  material: 'Состав: ...',
  images: ['images/item-1.jpg', 'images/item-2.jpg', 'images/item-3.jpg'],
  colors: [{ name: 'Чёрный', hex: '#111111' }],
  sizes: ['XS', 'S', 'M', 'L', 'XL', 'XXL'],
  sizeChart: {
    headers: ['Размер', 'Грудь (см)', 'Длина (см)'],
    rows: [['XS', '80–84', '64']],
  },
}
```

**Пример запроса:**
> "Добавь кепку и носки. У кепки один размер — 56-58. Цвета: чёрный, красный."
