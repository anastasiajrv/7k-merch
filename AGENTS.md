# Команда агентов — 7K Team × Oraz Merch Shop

Полная команда для создания профессионального онлайн-магазина мерча.

---

## ПРИОРИТЕТ 1 — Без этого сайт не работает

### 📸 Photographer / Art Director — Фотограф
**Задача:** Реальные фото товаров. Фото — 80% успеха.

**Что снимать:**
- Каждый товар: спереди, сзади, деталь крупным планом
- Лайфстайл: команда в форме на тренировке
- Флэтлей: форма красиво разложена сверху
- Фактура ткани и швов

**Требования к файлам:**
- Соотношение **1:1** (квадрат) или **4:5**, минимум 1000×1000 px
- Формат JPG или PNG, белый/нейтральный фон
- Папка `images/`, имена: `tshirt-front.jpg`, `tshirt-back.jpg`, `shorts-front.jpg` и т.д.

**Активировать:** *"Добавь фото [товара]"* — скинь файлы, Claude обновит каталог.

## ПРИОРИТЕТ 2 — Делают сайт красивым и удобным

### 🖌️ Visual Design Agent — Визуальный дизайнер
**Задача:** Поднять уровень дизайна — от "работает" до "вау".

**Может:**
- Улучшить hero-секцию (полноэкранное фото, видео-фон, параллакс)
- Добавить текстуры, градиенты, геометрические акценты
- Настроить типографику — крупные заголовки, контраст
- Добавить разделы: «Женщинам», «Мужчинам», «Хиты»

**Активировать:** *"Сделай hero как у Nike — тёмный фон, крупный слоган, атмосфера"*

---

### ✍️ Copywriter Agent — Копирайтер
**Задача:** Тексты, которые продают.

**Может:**
- Переписать описания товаров — коротко, энергично, в стиле 7K
- Сделать сильные заголовки и CTA
- Создать tone of voice: дерзкий, мотивирующий, командный

**Активировать:** *"Перепиши описания всех товаров в стиле 7K"*

---

### 🎞️ Motion / Animation Agent — Аниматор
**Задача:** Жизнь и премиум-ощущение через анимации.

**Может:**
- Scroll-reveal: карточки появляются при прокрутке
- Parallax в hero
- Hover-эффекты на карточках и кнопках
- Плавное открытие detail panel
- Skeleton-loading пока грузятся фото

**Активировать:** *"Добавь анимации появления карточек — снизу вверх, stagger 100ms"*

---

### 📱 Mobile/UX Agent — Мобайл и юзабилити
**Задача:** Идеальный опыт на телефоне.

**Может:**
- Свайп по галерее товара пальцем
- Sticky кнопка «Заказать» внизу экрана на мобайле
- Адаптировать detail panel под маленький экран
- Проверить все breakpoints (375px, 390px, 768px)

**Активировать:** *"Сделай свайп по фото на телефоне"*

---

### 🔍 SEO Agent — Поисковая оптимизация
**Задача:** Чтобы магазин находили в Google.

**Может:**
- Добавить meta-теги (title, description, keywords)
- Structured data (JSON-LD) для товаров — Google покажет фото и цену в выдаче
- Open Graph теги — красивая превьюшка при шаринге в соцсетях
- sitemap.xml и robots.txt

**Активировать:** *"Добавь SEO и Open Graph для шаринга"*

---

### ⚡ Performance Agent — Скорость
**Задача:** Сайт грузится мгновенно.

**Может:**
- Сжать изображения в WebP без потери качества
- Настроить lazy loading для фото
- Минифицировать CSS и JS
- Добавить кэширование через Service Worker

**Активировать:** *"Оптимизируй скорость загрузки"*

## ПРИОРИТЕТ 3 — Масштабирование и продажи

### 📦 Catalog Agent — Менеджер каталога
**Задача:** Добавлять и редактировать товары.

**Файл:** `script.js` → массив `products`

```js
{
  id: 'unique-id',
  name: 'Название',
  category: 'Категория',
  badge: null,           // 'Новинка' | 'Хит' | null
  description: '...',
  material: 'Состав: ...',
  images: ['images/item-front.jpg', 'images/item-back.jpg'],
  colors: [{ name: 'Чёрный', hex: '#111111' }],
  sizes: ['XS', 'S', 'M', 'L', 'XL', 'XXL'],
  sizeChartImage: 'images/item-size-chart.jpg', // опционально
}
```

**Активировать:** *"Добавь кепку — один размер 56-58, цвета: чёрный, красный"*

---

### 📬 Order Agent — Управление заказами
**Задача:** Принимать заказы и не терять их.

**Текущий статус:** Кнопка «Заказать» → письмо на gen@alconost.com

**Может улучшить:**
- Подключить Google Form → данные в таблице автоматически
- Telegram-бот → уведомления в чат моментально
- Форма прямо на сайте с валидацией
- Поля: имя, телефон, размер, цвет, количество

**Активировать:** *"Подключи Google Form. Вот ссылка: https://..."*

---

### 📊 Analytics Agent — Аналитика
**Задача:** Знать что работает, что нет.

**Может:**
- Подключить Yandex Metrica или Google Analytics
- Отслеживать клики «Заказать» и «Размерная сетка»
- Тепловые карты — куда смотрят посетители
- Воронка: зашёл → открыл товар → нажал «Заказать»

**Активировать:** *"Добавь Яндекс Метрику. Мой ID: XXXXXXXX"*

---

### 🌍 Social Media Agent — Соцсети
**Задача:** Красиво выглядеть при шаринге.

**Может:**
- Open Graph: превьюшка с фото товара при отправке ссылки
- Кнопки «Поделиться» в Telegram / Instagram
- Генерировать картинки для постов (размеры под каждую соцсеть)

**Активировать:** *"Добавь кнопку «Поделиться в Telegram»"*
